CINEVERSE | 팀 공통 RAG 설정 결정 실험 보고서

랙랙무비 · OpenAI 임베딩 / 검색 구조 비교

목적: Vector·Hybrid·Query Rewrite·Re-ranking·청킹에 대한 팀 공통 설정을 결정하기 위한 실험이다. 개인 브랜치와 팀 DB와 분리된 PostgreSQL 컬렉션에서 실행했으며, 팀원 결과와 수치를 직접 합산하지 않고 동일 조건 확정을 위한 근거로 사용한다.

1. 핵심 결과

방식Hit@5MRR
Vector A3/200.070
Hybrid B3/200.070
English Rewrite + 단순 재랭킹9/200.228
English Rewrite + Cross-Encoder13/200.471

Query Rewrite와 실제 Cross-Encoder 재랭킹이 가장 강한 개선 후보로 확인됐다.

2. 실험 흐름

팀 데이터셋 → 근거 문서 추출 → 1,584청크 → OpenAI 임베딩 → 개인 pgvector
→ Vector / Hybrid → Query Rewrite → Cross-Encoder → Top-5 근거
→ 답변 생성 → 자동 평가 → 인사이트 → 팀 설정 확정

4. 핵심 인사이트

  1. 한국어 질문을 영어 검색어로 변환하면 영어 위키 검색에 유리하다.
  2. Hybrid는 자동 개선이 아니며 RRF와 BM25 설정을 검증해야 한다.
  3. 단순 문자열 겹침보다 Cross-Encoder가 재랭킹에 적합하다.
  4. Overlap은 문서 유형별 차등 적용이 필요하다.
  5. 짧은 Top-5 문맥에서는 Context 배치 순서의 우위가 확정되지 않았다.

6. 한계

팀원 실험과 데이터·청킹·질문 세트가 다르며, 답변 평가는 LLM 자동 판정이다. RAGAS, 수동 교차 검토, 한국어용 Cross-Encoder 비교, 팀 서비스 통합은 남아 있다.
