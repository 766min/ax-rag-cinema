## ⓪ 취합본이 dev 가 되기까지

**순서** — ① 다섯 사람이 각자 브랜치(`exp/*`)에서 1차 실험 → ② 2026-11-26 다섯 브랜치에서 부품을 골라 dev 공통 환경 하나로 조립(로컬 `exp/gather`, 테스트 265개) → ③ 그 코드를 **맡은 사람이 다시 짜서** 파일 묶음마다 PR 로 올림 → ④ dev 에서 잰 결과로 설정을 고침.

③ 을 한 번에 올리지 않고 나눈 이유는 둘이다. `exp/*` 브랜치의 PR 은 CI 가 막고, PR 하나가 혼자서 검사(ruff · 형식 · mypy · pytest)를 통과하려면 그 파일이 가져다 쓰는 파일이 dev 에 먼저 있어야 한다. 그래서 순서는 "누가 먼저 끝내나" 가 아니라 **"무엇이 무엇을 가져다 쓰나"** 로 정했다. 여러 사람의 소스를 함께 보던 테스트 파일 셋은 그것이 보는 소스와 같은 PR 로 갈라 옮겼다.

## ③ 팀원별 시도 · 관찰 · 한계, 채택 · 실험 옵션 · 보류

수치마다 **문서 범위 · 문항 수 · 질의 언어 · 정답 인정 기준**을 같은 줄에 둔다. 서로 다른 조건의 수치라 직접 견주지 않는다. 아래 다섯 묶음은 1차 실험의 기록이다.

### 영민 [기존 기록: 이영민_CINEVERSE-진행-정리.md · exp/youngmin README]
- **조건**: 134문서(작품 68 · 인물 63 · 세계관 3) · 색인 2,197행(청크 1,966 + 카드 159 + 연결 72) · 공통 20문항(정답 키 19) · 한국어 질문 · 정답 청크 키 Hit@5.
- **시도 → 관찰**: A 3 · B 2 · C 3 · C+ 13~14 /19 (후보 20 안: 5 · 4 · 4 · 16). 질의 언어가 병목 — "타임 스톤이 뭐야?" 의 1위가 코사인 0.26 의 〈에코〉 줄거리. 후보 40 으로 늘리면 후보 안 16 → 18 이지만 상위 5 는 13 → 10, 재정렬 2.8 → 5.3초. min300 병합은 12 (흔들림 안). 프롬프트 p2-parts 로 사실 충족률 0.63 → 0.74, 부모 절 ≤3,000자는 엄격 6 → 7~8 · 충족률 0.73 (비슷) · 입력 토큰 약 60% 증가. 채점기 검사 기준 답안 17/19 통과 · 다른 문항 답안 0/19.
- **한계**: 결과 파일 원격 미공유, 부모 절 실행은 리라이트가 달라 검색부터 달랐다(효과 분리 안 됨), 머리말 효과 미측정, README 의 프롬프트 판(p0-smoke)이 코드(p2-parts)와 다름.
- **채택**: 범위 규칙 · 카드 · 증분 적재 · 정답 키 매핑 · 채점기 · 원 질문 생성. **실험 옵션**: 부모 문맥(`--context parent`). **보류**: 문단 단위 청킹(기준선은 800자 문장 경계).

### 민지 [기존 기록: 김민지_eval-report2.md · insights/chunking-eval-report.md]
- **조건**: S2 데이터 413문서 · 공통 20문항(답변 가능 19) + 함정 3 · 팀 번역 도구로 만든 고정 영문 검색어 · 벡터 후보 20 중 5 전달(= A+ 형) · 섹션 적중 · 발췌 적중.
- **시도 → 관찰**: 400 · 800 · 1,600자 × 겹침 0 · 1문장. 800자 섹션 Hit@5 0.842(16/19), 무겹침 · 한 문장 겹침 모두 섹션 16/19 · 답변 완전 충족 4/19(LLM 판정), 겹침 시 발췌 적중 13 → 14 · 평균 입력 1,110 → 1,226토큰. 섹션당 1개 상한은 섹션 16 → 17 이지만 발췌 13 → 9. 상한으로 잃은 5문항은 앞뒤 원문 3,000자 사전 계산에서 모두 복구(실행 전).
- **한계**: 답 채점은 생성과 같은 모델의 LLM 판정이며 채점기 검사 기록 없음(참고값). 보고서는 '결과 파일 커밋 안 함' 이라 적었지만 `results/` 39개가 커밋돼 있다. chunk_id 가 dev 규칙과 다르다(`{doc}-s{NNN}-p{NNN}`).
- **채택**: 문장 분할기 · 실패 분류 · 원문 위치 설계. **실험 옵션**: `s800-o1`. **보류**: 섹션 상한 선택(정답 문장 손실).
